GitHub Pages:
1. Neues öffentliches Repository anlegen, z.B. lkw-navi.
2. Diese fünf Dateien in die oberste Ebene des Repositories hochladen.
3. Settings > Pages öffnen.
4. Als Quelle 'Deploy from a branch' wählen, Branch 'main', Ordner '/ (root)'.
5. Nach der Veröffentlichung die HTTPS-Adresse in Safari auf dem iPhone öffnen.
6. Teilen > Zum Home-Bildschirm.

WICHTIG:
Dies ist ein Prototyp. OpenStreetMap-/Routingdaten können fehlen oder falsch sein.
Verkehrszeichen und behördliche Beschränkungen haben immer Vorrang.
